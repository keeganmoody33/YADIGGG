# Component-selection history

This page no longer represents a sourcing register. The former tables contained conflicting, unverified part numbers, package descriptions, distributor IDs, and price estimates; none were approved for purchasing. The original tables are preserved in the [historical proposal archive](../archive/historical-proposals/component-selections.md).

The only maintained machine-readable list is [`manufacturing/draft-bom.csv`](../manufacturing/draft-bom.csv). It preserves candidate values and their source documents, labels each unverified, and records known conflicts. It is not an approved BOM. See [ADR-0007](adr/0007-component-bom-is-conflicted-and-needs-reconciliation.md) and the [readiness register](project-state.md) for the required reconciliation and closure evidence.
