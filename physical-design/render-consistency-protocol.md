# Concept-render review protocol

Use this protocol only for visual exploration. The [product specification](final-product-source-of-truth.md) is the sole current product-direction source; renders cannot establish dimensions, component choices, fit, materials, or manufacturing readiness.

## Current visual intent

- Compact, portrait-first pocket field recorder / crate-digging assistant.
- Smoke-clear appearance, monochrome display concept, and amber side-control concept.
- Restrained visible dark internals; lowercase `yadiggg` or no visible branding.
- No keypad, Crate IQ branding, or unrelated walkie-talkie form.

The `105 × 60 × 15 mm` envelope is provisional visual context only. Display technology/part, control mechanism, connectors, camera, microphones, battery, resin, finish, and internal layout are unresolved. Historical references under `assets/reference/` are not requirements.

## Prompt and review

Use the following reusable prompt stem, then specify one scene or view:

> Create concept art for the current yadiggg visual direction described in `physical-design/final-product-source-of-truth.md`. Preserve the compact portrait-first field-recorder archetype, smoke-clear appearance, monochrome display concept, and amber side-control concept. Treat all proportions and internal details as illustrative; do not imply selected components, measured dimensions, verified fit, production materials, or manufacturing approval. Label the result as concept art.

Possible scene additions: studio hero, front/back/side concept sheet, conceptual exploded stack, or one-handed crate-digging lifestyle scene. An exploded image must not be described as a verified assembly.

Reject or annotate any render that:

- silently changes the current visual direction or adds Crate IQ branding;
- presents an exact display, camera, jack, battery, material, dimensions, port layout, or internal stack as selected;
- resembles a measured drawing, CAD, test result, certification, or released-for-manufacture artifact;
- obscures which elements are speculative.

The [readiness register](../docs/project-state.md) controls engineering status. Do not copy product requirements into render prompts; link to the specification instead.
