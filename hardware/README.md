# Hardware artifacts

The KiCad project files in this directory are incomplete scaffolds, not a circuit or fabrication package. The [readiness register](../docs/project-state.md) records the required electrical and mechanical closure evidence.

The CAD/EDA notes and source proposals moved to [`archive/historical-proposals/`](../archive/README.md) contain unverified candidate parts and must not be used as approved design inputs. The current product intent is in the [product specification](../physical-design/final-product-source-of-truth.md); supplier scope is in the [manufacturer handoff](../manufacturing/handoff.md).

The maintained Yocto repository paths are documented in [build notes](yadiggg_yocto_recipe_and_image_build.md).
